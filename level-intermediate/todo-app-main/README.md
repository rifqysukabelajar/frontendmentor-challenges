# Frontend Mentor - Todo app

![Design preview for the Todo app coding challenge](preview.jpg)

## Welcome! 👋

A Todo List application built as part of a Frontend Mentor challenge.
This project focuses on implementing core todo functionalities, state management,
and user-friendly interactions using vanilla JavaScript.

## 🚀 Demo

Live demo: https://rifqysukabelajar.github.io/frontendmentor-challenges/level-intermediate/todo-app-main/src/index.html

## 🧩 Features

- Add todos
- Delete todos
- Mark todos as todos
- Filter todos (all, active, completed)
- Dark mode
- Show error message when input is empty

## 🛠️ Built With

- Semantic HTML5
- CSS ( Flexbox, Grid, CSS Variables, Semantic Colors )
- Mobile-first workflow
- Vanila JavaScript

## 🧠 What I Learned

- Refactoring functions to be more reusable and easier to maintain
- Structuring JavaScript code into multiple files based on responsibility
- Organizing project folders for better scalability (assets, services, ui, utils, etc.)
- Managing application state without frameworks
- Persisting application state using localStorage
- Synchronizing UI with stored data
- Implementing input validation and UI-level error handling
- Building semantic and accessible HTML structure
- Improving user experience with features like dark mode and filters
- Using Git and GitHub more effectively (committing specific files)
- Applying basic commit message conventions to improve collaboration and code readability
